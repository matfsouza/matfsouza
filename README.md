### ⭐ Projeto em Destaque

📌 **[Smart Inventory Backend - API de Gerenciamento Inteligente de Estoque](https://github.com/matfsouza/smart-inventory-backend)**
   - Uma API RESTful completa construída com **Java e Spring Boot** que gerencia produtos e utiliza o histórico de vendas para **prever a necessidade de ressuprimento**.
   - Possui um sistema de segurança robusto com **Spring Security e Tokens JWT**, incluindo registro e login de usuários.
   - O ambiente do banco de dados **MySQL** é totalmente gerenciado e portabilizado com **Docker**.
